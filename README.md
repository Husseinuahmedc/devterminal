# devterminal
> Custom Linux CLI tool for managing notes and dev workflows.

![Python](https://img.shields.io/badge/python-3.10+-blue) ![CLI](https://img.shields.io/badge/interface-terminal-black) ![Linux](https://img.shields.io/badge/os-linux-FCC624)

## What it does
Manages developer notes and snippets directly from the terminal.
Provides fast search, retrieval, and tagging for structured knowledge.
Designed for Linux power users who live in the terminal.

## Tech Stack
- Python, Bash, Shell

## Quick Start
```bash
git clone https://github.com/Husseinuahmedc/devterminal
cd devterminal
bash install.sh
devterminal add "note"
devterminal list
devterminal search "keyword"
```
